# Сервис регистрации продавцов на ярмарку (FairVendor)

Консольное приложение для регистрации продавцов, учета ярмарочных мероприятий, проверки доступности торговых площадей, расчета сборов и управления заявками.

Разработано в рамках дисциплины «Технологии разработки приложений на базе фреймворков».

## Назначение
Сервис предназначен для автоматизации подачи и обработки заявок от продавцов, фермеров и ремесленников на участие в ярмарочных мероприятиях. Приложение позволяет ускорить регистрацию участников, автоматизировать проверку реквизитов, рассчитывать стоимость аренды торгового места с учетом специфики продукции и лимитов площадей, а также формировать официальное подтверждение участия.

## Целевая аудитория
- **Продавцы и ремесленники:** индивидуальные предприниматели, самозанятые мастера и фермерские хозяйства, бронирующие торговые места на ярмарке.
- **Организаторы и администраторы ярмарок:** координаторы площадки, ответственные за проверку документов, утверждение заявок, учет свободных площадей и финансовый контроль.

## Предметная область
Предметная область охватывает процессы организации сезонных, тематических и городских ярмарок: ведение реестра мероприятий, учет характеристик торговых площадок (лимит площади, базовая ставка), валидацию категорий продукции (ремесла, фермерские товары, сувениры) и управление жизненным циклом заявок на участие.

## Основные сущности
- **Продавец (Vendor)** — субъект торговли (ID, наименование бренда/ФИО мастера, ИНН, категория продукции, статус документов, стаж участия).
- **Ярмарка (Fair)** — мероприятие (ID, название, площадка, дата проведения, базовая ставка за кв.м, лимит общей площади).
- **Категория товара (Category)** — специфика реализуемых изделий, определяющая тарифный коэффициент.
- **Заявка на участие (Application)** — регистрационный документ, фиксирующий ID продавца и ярмарки, площадь стенда, рассчитанную сумму сбора и статус решения.

## Возможности (ПР2)
- просмотр перечня ярмарок с расчетом занятой и свободной площади;
- просмотр, регистрация и поиск продавцов по наименованию (регистронезависимый поиск);
- поэлементная фильтрация продавцов по категории товаров с использованием генератора (`yield`);
- сортировка продавцов по имени или торговому стажу с использованием `lambda`-функций;
- проверка лимита торговых площадей ярмарки перед регистрацией;
- расчет стоимости участия с учетом коэффициента товарной категории и скидки за первое участие;
- регистрация новых заявок и формирование структурированной карточки участника;
- отзыв и отмена поданных заявок с автоматическим освобождением площади;
- расчет сводной аналитики и статистики ярмарочной площадки (заполняемость, выручка, число одобренных заявок);
- персистентное сохранение и загрузка данных в формате JSON с контекстными менеджерами `with open`;
- надежная обработка исключительных ситуаций (`ValueError`, `FileNotFoundError`, `json.JSONDecodeError`).

## Структура проекта
- `main.py` — точка запуска приложения с интерактивным текстовым меню и автоматическим демонстрационным режимом (`--demo`);
- `vendors.py` — модуль работы с реестром продавцов (валидация ИНН, регистрация, поиск, генератор фильтрации, сортировка через `lambda`);
- `applications.py` — модуль управления заявками (расчет сборов, проверка доступности площадей, создание и отмена заявок, аналитика ярмарок);
- `storage.py` — модуль персистентного хранения данных в формате JSON с обработкой ошибок;
- `utils.py` — вспомогательные функции безопасного ввода (`try/except ValueError`) и форматирования валюты;
- `data/` — каталог с JSON-файлами данных (`fairs.json`, `vendors.json`, `applications.json`);
- `tests/` — каталог с автоматизированными модульными тестами `pytest` (`test_vendors.py`, `test_applications.py`);
- `test_main.py` — тесты обратной совместимости функций начального уровня;
- `requirements.txt` — зависимости проекта (`pytest`, `flake8`, `reportlab`, `pymupdf`);
- `.flake8` — файл конфигурации линтера стандартов оформления PEP 8.
