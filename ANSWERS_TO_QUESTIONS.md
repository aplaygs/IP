### По материалам Яндекс Практикума

#### 1. Какие основные типы данных используются в Python?
В Python используются:
- Простые скалярные типы: целые числа (`int`), вещественные числа с плавающей точкой (`float`), строки (`str`), логические значения (`bool`), специальный тип отсутствия значения (`NoneType`).
- Коллекции и контейнеры (изучаются в ПР2): списки (`list`), кортежи (`tuple`), словари (`dict`), множества (`set`, `frozenset`).

#### 2. Чем отличаются int, float, str и bool?
- `int` — целые числа произвольной точности (например, `10`, `-5`).
- `float` — числа с плавающей точкой двойной точности по стандарту IEEE 754 (например, `3.14`, `1500.0`).
- `str` — неизменяемые последовательности символов Unicode (текст, строки, например `"Мастерская"`).
- `bool` — логический тип, принимающий только одно из двух значений: `True` (истина) или `False` (ложь); является подклассом `int` (1 и 0).

#### 3. Для чего используется преобразование типов?
Преобразование (приведение) типов используется для явного приведения значения одной структуры данных к другой для корректного выполнения операций (например, сложения числа и строки, парсинга пользовательского ввода `int("10")` или форматирования числа в строку `str(1500)`).

#### 4. Какие операции можно выполнять со строками?
- Конкатенация (`+`) и дублирование (`*`);
- Срезы (`s[start:stop:step]`) и индексация;
- Форматирование (f-строки `f"{var}"`, метод `.format()`, оператор `%`);
- Методы проверки и преобразования: `.strip()`, `.lower()`, `.upper()`, `.isdigit()`, `.replace()`, `.split()`, `.join()` и др.;
- Проверка вхождения подстроки (`in`, `not in`).

#### 5. Какие операторы сравнения используются в Python?
- Равно: `==`
- Не равно: `!=`
- Меньше / Больше: `<` / `>`
- Меньше или равно / Больше или равно: `<=` / `>=`
- Идентичность объектов: `is`, `is not`

#### 6. Для чего используется конструкция if?
Конструкция `if` предназначена для ветвления логики выполнения программы: блок инструкций под `if` выполняется только тогда, когда проверяемое условие принимает логическое значение `True`.

#### 7. В чем различие между if, elif и else?
- `if` — проверяет первое условие в цепочке ветвления;
- `elif` (else-if) — проверяет альтернативное условие, только если все предшествующие `if` и `elif` оказались ложными (`False`);
- `else` — выполняется гарантированно, если ни одно из предшествующих условий `if` и `elif` не было выполнено.

#### 8. Как записываются составные условия?
Составные условия объединяются с помощью логических операторов `and` (логическое И), `or` (логическое ИЛИ) и `not` (логическое НЕ). Для явного задания приоритета вычислений используются круглые скобки `( ... )`.

#### 9. Для чего используются логические операторы and, or и not?
- `and` возвращает истину, если **оба** операнда истинны;
- `or` возвращает истину, если **хотя бы один** из операндов истинен;
- `not` инвертирует логическое значение (меняет `True` на `False` и наоборот).

#### 10. Что такое модуль Python?
Модуль в Python — это отдельный файл с расширением `.py`, содержащий определения функций, классов, переменных и исполняемый код, предназначенный для повторного использования в других программах.

#### 11. Для чего используется import?
Оператор `import` используется для подключения модулей, пакетов или библиотек (как стандартных, входящих в поставку Python, так и внешних, установленных через pip) к текущему пространству имен программы.

#### 12. Чем импорт модуля отличается от импорта отдельного объекта из модуля?
- `import datetime` импортирует модуль целиком; доступ к объектам внутри осуществляется через точечную нотацию: `datetime.date(2026, 10, 15)`.
- `from datetime import date` импортирует только конкретный объект `date` напрямую в текущее пространство имен, что позволяет вызывать его без префикса: `date(2026, 10, 15)`.

### По рабочему окружению

#### 13. Для чего используется виртуальное окружение Python?
Виртуальное окружение (`venv`) создает изолированную директорию с собственной версией интерпретатора и набором установленных библиотек. Это предотвращает конфликты версий зависимостей между различными проектами и изолирует их от глобального системного окружения.

#### 14. Что такое IDE?
IDE (Integrated Development Environment) — интегрированная среда разработки (например, VS Code, PyCharm, Antigravity IDE), объединяющая в одном интерфейсе текстовый редактор с подсветкой синтаксиса, терминал, менеджер файлов, отладчик и инструменты интеграции с Git.

#### 15. Для чего используется Git?
Git — это распределенная система контроля версий, предназначенная для отслеживания изменений в исходном коде проекта, координации совместной работы, создания веток разработки и возможности возврата к любому предыдущему состоянию кодовой базы.

#### 16. Что такое репозиторий?
Репозиторий — это хранилище проекта (каталог с базой данных изменений `.git`), в котором сохраняются файлы исходного кода, их история версий, коммиты, ветки и конфигурационные метаданные.

#### 17. Что такое commit?
Коммит (commit) — это зафиксированный снимок (snapshot) состояния файлов проекта в определенный момент времени, имеющий уникальный хэш-идентификатор (SHA-1), автора, дату и поясняющее сообщение.

#### 18. Для чего нужен .gitignore?
Файл `.gitignore` указывает системе Git, какие файлы, расширения и директории следует исключить из отслеживания версий (например, виртуальные окружения `.venv`, временные файлы кэша `__pycache__`, системные файлы `.DS_Store`, ключи и конфиденциальные данные).

#### 19. Для чего нужен README.md?
Файл `README.md` является «визитной карточкой» репозитория. Он написан на языке разметки Markdown и описывает назначение проекта, инструкции по установке и запуску, архитектуру, состав сущностей, функционал и планы развития.

#### 20. Что такое отладка?
Отладка (debugging) — процесс обнаружения, локализации, анализа и устранения ошибок (багов) и неожиданного поведения в программном обеспечении с использованием специализированных инструментов.

#### 21. Что такое breakpoint?
Точка останова (breakpoint) — специальная марка в исходном коде, предписывающая отладчику приостановить выполнение программы на заданной строке до ее исполнения, позволяя разработчику изучить текущее состояние программы.

#### 22. Для чего используется пошаговое выполнение программы?
Пошаговое выполнение (Step Over / Step Into) позволяет выполнять код построчно, наблюдая за изменением значений локальных и глобальных переменных в памяти в реальном времени и проверяя логику переходов внутри условных ветвлений.

### По индивидуальному проекту

#### 23. Какую задачу решает выбранное приложение?
Приложение «Сервис регистрации продавцов на ярмарку» автоматизирует регистрацию мастеров, фермеров и ремесленников, проверяет корректность документов, рассчитывает стоимость аренды торгового места с учетом специфики товара и управляет статусами заявок.

#### 24. Кто является предполагаемым пользователем?
- Продавцы, фермеры и ремесленники (подача заявок, выбор категории, бронирование места).
- Администраторы и координаторы ярмарок (проверка документов, учет площадей, финансовый контроль, модерация заявок).

#### 25. Какие основные сущности выделены в предметной области?
1. **Продавец (Vendor)** — данные мастера/организации, ИНН, статус документов;
2. **Ярмарка (Fair)** — мероприятие, площадка, дата, вместимость, базовый тариф;
3. **Категория (Category)** — специфика продукции, отраслевой коэффициент тарификации;
4. **Заявка (Application)** — запрос на бронирование места с расчетом сбора и статусом.

#### 26. Какие функции планируется реализовать?
- Валидация реквизитов и документов продавца;
- Расчет арендной платы стенда с учетом категории и льгот;
- Проверка доступности торговой площади и присвоение статуса заявке;
- Формирование карточки участника ярмарки;
- В дальнейшем: личные кабинеты, фильтрация каталога, оплата онлайн, админка Django, REST API.

#### 27. Какой сценарий реализован на текущем этапе?
Реализован базовый сценарий обработки заявки: поступают данные продавца керамики, валидируется ИНН и пакет документов, рассчитывается стоимость стенда со скидкой 15% для новичка, проверяется остаток свободной площади ярмарки и генерируется итоговая регистрационная карточка.

#### 28. Какие конструкции Python использованы в программе?
- Простые типы: `int`, `float`, `str`, `bool`;
- Модули стандартной библиотеки: `from datetime import date`;
- Ветвления: `if`, `elif`, `else` с составными условиями (`and`, `or`, `not`);
- Пользовательские функции с аннотациями типов (`type hints`) и docstring;
- Преобразование типов (`round`, `len`, `strip`, `isdigit`, f-строки).

#### 29. Какие части проекта будут добавлены после изучения ООП и Django?
- ООП (ПР3): сущности будут инкапсулированы в классы `Vendor`, `Fair`, `Application`, `Category` с методами бизнес-логики;
- Веб и Django (ПР5–ПР11): ORM-модели для СУБД, миграции, HTML-шаблоны страниц, веб-формы регистрации, авторизация пользователей (роли продавца и администратора);
- API и развертывание (ПР13–ПР16): Django REST Framework, автоматизированные тесты Pytest, Docker-контейнеры.

#### 30. Почему выбранная предметная область подходит для дальнейшей реализации в виде веб-приложения?
Предметная область ярмарочных мероприятий идеально ложится на архитектуру веб-приложений:
- Включает несколько взаимосвязанных сущностей с отношениями один-ко-многим и многие-ко-многим;
- Требует разграничения прав доступа (гости просматривают ярмарки, продавцы подают заявки, организаторы утверждают их);
- Имеет четкие CRUD-операции (создание, чтение, редактирование, удаление мероприятий и заявок);
- Легко масштабируется добавлением REST API для мобильных клиентов и интеграции с платежными шлюзами.
